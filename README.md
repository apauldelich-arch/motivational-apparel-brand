# DELITE Landing Page

Local Next.js concept-validation landing page for DELITE. It uses the supplied logo and apparel concept images; product images are explicitly shown as concepts, not live inventory.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validate

```bash
npm run build
```

## Early access

The form validates locally and shows a clear development-mode notice after submission. It does not store email addresses. Connect a secure server-side endpoint before collecting real registrations.

## Production inputs still required

- Approved DELITE logo treatment and licensing confirmation for imagery
- Final garment photography and product specifications
- Privacy policy, contact address and Instagram URL
- A backend and consent/audit process for early-access registrations
